# 🍔 Burger House Online Order Form

A simple and responsive **Burger House Online Order Form** created using **HTML5**. This project is designed to practice HTML form elements and semantic tags without using external CSS or JavaScript.

## 📌 Project Overview

This project simulates an online burger ordering system where users can:

- Enter personal information
- Choose a burger type
- Select burger size
- Pick extra add-ons
- Choose a preferred delivery time
- Add special delivery instructions
- Submit or reset the form

## 🚀 Features

- HTML5 Document Structure
- Customer Information Form
- Required Input Fields
- Radio Buttons
- Checkboxes
- Time Input
- Textarea
- Submit Button
- Reset Button
- Fieldset and Legend for grouped inputs
- Table-based layout for form alignment
